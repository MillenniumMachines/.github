# Millennium Machines

We specialise in subtractive manufacturing, and are working to create a robust ecosystem of machines based on open-source values that have been made popular by projects like [Voron Design](https://github.com/voronDesign/).

Our flagship machine is the **Millennium Machines Milo V2.0**, a CNC milling machine that can fit onto any desktop or in any garage, can be built without needing any special tools or expertise, and without breaking the bank.

## Thank you

Millennium Machines is built by volunteers. These past maintainers were part of the core team and helped build the Milo and its ecosystem, and we're grateful for everything they did.

- **[@8000ff](https://github.com/8000ff)** ported the Milo V1.5 manual from PDF to Markdown, set the STLs in their print orientation, and contributed Milo and Casa parts.
- **[@bazil14](https://github.com/bazil14)** updated the Milo V1.5 print list and tool library, made rendered images for the documentation, and added the HOI spindle mounts to UserMods.
- **[@bdistin](https://github.com/bdistin)** fixed and extended MillenniumOS and its Fusion post-processor, proofread the whole documentation site, and added the Casa drill guides.
- **[@dmason1992](https://github.com/dmason1992)** created the Milo V1.5 starter tool library, and added the plate clamp and its documentation to F.I.X.A.T.E.D.
- **[@EdwardChamberlain](https://github.com/EdwardChamberlain)** set up much of the documentation site, wrote the Long John and Casa build guides, and contributed fixes to the Milo V1.5 parts.
- **[@Mobserva](https://github.com/Mobserva)** designed the Monoskirt, one of the first contributions to Milo V1.5.
